Chapter 02: Secondary Sorting
==========
The purpose of this chapter is to associate sorted 
values with reducer keys. For example, if our input has 
an ordering over values for each key as in a 
time series (a sample is given below), the values for 
each key should be sorted (e.g. by time) after reducing.

Package 
=======
org.dataalgorithms.chap02.mapreduce

Classes
=======

Class Name                   | Description                                |
---------------------------- | ------------------------------------------ | 
CompositeKey                 | Defines a composite key                    | 
CompositeKeyComparator       | Defines how a CompositeKey will be sorted  | 
NaturalKeyGroupingComparator | Defines how a NaturalKey is sorted         | 
NaturalKeyPartitioner        | Defines partitioning of NaturalKey(s)      | 
NaturalValue                 | Defines a NaturalValue                     | 
SecondarySortDriver          | Driver to submit a MapReduce job           | 
SecondarySortMapper          | Defines map()                              | 
SecondarySortReducer         | Defines reduce()                           | 

Sample Data Prep and Script
============================

A small sample of input data for this example is provided within the book and may be copied by hand from the page into a CSV file, or compatible data may be extracted from many places (just a CSV of stock symbol, date in YYYY-MM-dd, price).
One such place for a realistic scale dataset is the Apache 2 licensed "Historical Stock Prices Dataset" on Kaggle at https://www.kaggle.com/datasets/anitarostami/historical-stock-price-dataset?resource=download , which provides columns `Date,Open,High,Low,Close,Adj Close,Volume,Ticker` which can be mapped to the [columns expected by this example](https://github.com/mahmoudparsian/data-algorithms-book/blob/625c090e57f3551e65df9129d45eecb0c96d85fd/src/main/java/org/dataalgorithms/chap02/mapreduce/SecondarySortMapper.java#L39-L41) by `columns[7],columns[0],columns[4]`.

E.g. after downloading the Kaggle Historical stock price dataset, one can use the provided Java 8 compatible [PrepDataChap02 java program](https://github.com/mahmoudparsian/data-algorithms-book/blob/master/resource/chap02/PrepDataChap02.java) to prepare the data in the format expected (it will also randomize the order of the rows, mixing up stock symbols and dates, to make clearer the grouping and secondary sorting performed by the Hadoop program).

After which one can run this example as:
```
export DRIVER_CLASS_NAME="org.dataalgorithms.chap02.mapreduce.SecondarySortDriver"
export INPUT_FILE="/home/liveuser/Downloads/kaggle-stock-price-dataset-apache-licensed/StockPriceDataset-TransformedToMParsianChap02Format.csv" # replace with your own file, e.g. generated by PrepDataChap02
export OUTPUT_DIR="/tmp/output1"
$HADOOP_HOME/bin/hadoop jar $APP_JAR $DRIVER_CLASS_NAME $INPUT_FILE $OUTPUT_DIR 
```

(Assuming $HADOOP_HOME, $APP_JAR are configured as described elsewhere.
Most importantly, APP_JAR should point to `data_algorithms_book.jar` or `data-algorithms-book.jar`from the dist,target, or build/libs folder depending on whether ant, maven, or gradle were used to build it. Hadoop dependency jars should also be made available to Hadoop (the gradle build along with a default hadoop install should achieve this by default as needed for this example).)
